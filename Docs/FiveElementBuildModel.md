# 五行构筑数值模型 v0.1

这是一版用于验证方向的模型，不是正式 Unity 配置。它以当前网页构筑沙盒为校准参照：主射基础伤害 12，副射基础伤害 28，生命上限 100，单个掩体耐久上限 100，副射资源上限 100、消耗 35、恢复 8/s，普通敌人生命 12/18/36/72，精英 260，Boss 880。普通房清场时长以约 40 秒为调参目标，不设战斗倒计时；实际用时由出怪节奏、击杀速度和剩余敌人决定。

## 1. 建模边界

五行是角色的底层属性资源；新版流派（礼魂/大司命、湘夫人、云中君、少司命、太一、九凤、巫咸、河伯、海若、湘君、首山玄女等）作为主题与机制层。两者不要互相映射成同一套乘区，否则一件物品会同时重复放大伤害、防御和流派收益。

正式字段建议使用独立的 `metal / water / wood / fire / earth`。当前原型已经有 `FactionTag.water` 和 `FactionTag.earth`，它们是神话/流派标签，不能直接复用为五行属性。

当前原型里的 `aura` 是击杀经验和聚气资源，不能拿来表示水的法力或火的神力。五行接入时至少要把以下资源分开：

- 金：体力 `stamina`。
- 水：法力/副射资源 `mana`，可复用原型的 `secondaryEnergy` 语义。
- 木：生命 `life`。
- 火：神力 `divine`，用于大招或强力爆发。
- 土：掩体 `cover`，以及携带容量。

每种五行强度有两个明确消费者：

1. 对应属性伤害载荷，例如木伤、金伤、水伤、火伤、土伤；只有声明读取该元素的武器、技能、物品或灵体才使用它。
2. 角色资源派生，例如金影响气力、木影响生命、火影响神力。

元素伤害与资源派生不能互相偷渡机制：金伤不自动提高暴击，木伤不自动提高治疗，水伤不自动返还法力，火伤不自动提高攻速或神力获取，土伤不自动提高防御或失衡效率。暴击、攻速、回复、护盾和流派触发都由独立属性或效果明确提供。

## 2. 天赋倍率

设每个元素的角色基础值为 `C_e`，天赋档位索引为 `i = 0..14`，顺序从 `S+` 到 `D-`：

```text
m(i) = 2 - 1.8 * i / 14
T_e = C_e * (1 + m(i))
```

`T_e` 是角色的最终天赋强度。这里的倍率只作用于角色天赋基础值，不再乘到物品点数上，避免天赋倍率、物品数量和物品等级同时膨胀。

| 档位 | m | 基础值的最终倍数 |
| --- | ---: | ---: |
| S+ | 2.000 | 3.000 |
| S | 1.871 | 2.871 |
| S- | 1.743 | 2.743 |
| A+ | 1.614 | 2.614 |
| A | 1.486 | 2.486 |
| A- | 1.357 | 2.357 |
| B+ | 1.229 | 2.229 |
| B | 1.100 | 2.100 |
| B- | 0.971 | 1.971 |
| C+ | 0.843 | 1.843 |
| C | 0.714 | 1.714 |
| C- | 0.586 | 1.586 |
| D+ | 0.457 | 1.457 |
| D | 0.329 | 1.329 |
| D- | 0.200 | 1.200 |

第一版校准假设：`C_e = 4`，新角色五行初始均为 `C`。因此每个元素的天赋强度是 `4 × 1.714 = 6.857`，五行合计 `34.286`。如果改成全 B 初始，需要重新调整伤害系数，不能把两套基准混用。

## 3. 物品、赐福和最终元素强度

```text
I_e = 所有已装备物品提供的元素点
L_e = 赐福或其他永久效果提供的直接元素点
X_e = T_e + I_e + L_e
```

`X_e` 进入生命、法力、体力、神力、掩体和容量的派生公式，同时作为对应元素伤害载荷的公共基础值。赐福提升天赋时，建议记录为 `talentRankAdd`，并把档位限制在 `S+..D-`；不要用普通 `statAdd` 冒充。

当前原型物品等级的直接效果是线性放大：`1 + (倍率 - 1) × 等级`，不是幂乘。五行点也建议采用显式的每阶增量，例如普通物品每阶 `+1`，稀有每阶 `+1.5`，神话每阶 `+2`。

## 4. 基础伤害

推荐先把天赋伤害和物品伤害分开：

```text
basePrimary = 0.35 × Σ(T_e) + 0.10 × Σ(I_e + L_e)
```

全 C、无物品时 `0.35 × 34.286 = 12.0`，正好对齐当前原型。物品元素点以较低系数转成伤害，同时完整进入它们对应的五行功能；物品的显式 `primaryDamage`、`secondaryDamage` 和条件效果仍在此基础上结算。

网页原型第一轮按上面的分离系数实现：天赋增量使用 `0.35`，物品/赐福元素点使用 `0.10`。这样物品五行点会进入基础伤害，但不会因为背包数量把伤害迅速乘爆。若之后希望物品五行值等权进入伤害，可以改成 `0.35 × Σ(X_e)`，但一局元素点总预算要先压到约 10~20。

副射先保持原型关系：`baseSecondary = 2 × basePrimary + 4`。主射 12 时副射为 28，满蓄力倍率单独结算。后续每个动作应声明自己的伤害元素和载荷公式，不把整套五行总和重复附加到每个动作上。

## 5. 五行派生公式

以下公式以全 C、无物品时回到原型的 100/100/100/100 为目标。

### 金：体力

```text
staminaMax = 100 + 6 × (X金 - 6.857) + 6 × 气力储备加值
staminaRegen = 8 + 0.80 × X金  (每秒)
primaryCost = max(2.5, 8 - 0.18 × X金)
rollCost = 20  (正式翻滚接入时再单独校准)
```

全 C 时气力上限为 100、恢复约 13.5/s。当前原型每发主射固定消耗约 6.8 点，按 `R` 回气；每点气力储备加值增加 6 点上限。超重时额外提高消耗与射击间隔。攻击消耗减免建议硬上限 40%。

### 水：法力/副射资源

```text
manaMax = 50 + 7.292 × X水
manaRegen = min(12, 4 + 0.58 × X水)  (每秒)
secondaryCost = 35
```

全 C 时为 100 上限、8/s 恢复。水高的构筑应表现为更频繁使用技能，而不是同时拥有最高常驻伤害。

### 木：生命

```text
lifeMax = 50 + 7.292 × X木
```

木的主要价值是容错和恢复窗口，不建议再给木一层全局减伤，否则会与现有 `damageReduction` 叠成必选防御属性。

### 火：神力

```text
divineMax = clamp(100 + 7.3 × (X火 - 6.857), 80, 160)
divineRegen = 0.5 + 0.18 × X火  (每秒)
```

全 C 时神力上限为 100、神力恢复约 1.73/s。火高的构筑拥有更快的爆发窗口；大招消耗建议固定为满槽或 100 点，并为回能来源设置每房间/每秒上限。神力必须和 `aura` 分开。

### 土：掩体与携带

```text
coverMax = 100 + 7.3 × (X土 - 6.857)
coverReduction = clamp(0.35 + 0.015 × (X土 - 6.857), 0, 0.75)
weightCapacity = max(8, 24 + 1.75 × (X土 - 6.857))
```

全 C 时掩体约 100、掩体防护约 35%、负重上限 24。当前原型允许超过负重上限，超重会增加气力消耗、降低主射速度并禁用闪避；正式游戏仍建议把战斗主动槽和探索携带重量拆开。

## 7. 赐福和成长预算

单个天赋升一档的倍率差是 `0.12857`。当 `C_e=4` 时，只增加约 `0.514` 属性点，转成伤害约 `0.18`。因此赐福只写“某属性提升 1 档”会显得弱。

- 普通赐福：单系升 2 档，并给一个 10% 左右的专用机制效果。
- 稀有赐福：单系升 3 档，或两系各升 2 档，并带一个条件效果。
- 神话赐福：单系升 4 档或双系各升 2 档，附带一次房间级/大招级机制。
- 一局纯升档总量先控制在 8~10 档，升到 `S+` 后溢出转为直接元素点或专用效果。
- 物品元素点是独立预算：普通 4~6，稀有 7~10，神话 12~16；实际进入背包的总量先压在 50~80 以内。

如果五个天赋都能无限独立升高，五行全高在数学上永远支配专精构筑。必须至少使用一种机会成本：有限升档点、互斥赐福、每件物品只带 1~2 个元素，或固定总天赋预算。

## 8. 与当前代码的接入顺序

这份模型适合先接入网页沙盒验证，不应直接复制成 Unity 场景或配置：

1. 内容定义增加 `elementalStats`，与 `factionTags` 并列；物品类型标签不参与当前构筑。
2. `RunState` 增加天赋档位，旧存档迁移到全 C 或预设档位。
3. `resolveBuild` 按“角色天赋 → 物品/赐福元素点 → 五行派生 → 现有直接效果/羁绊”计算。
4. `ResolvedCombatBuild` 增加体力、法力、神力、生命、掩体、容量和五行强度快照。
5. `CombatState` 和 HUD 增加体力、法力、神力；`aura` 保持经验/聚气含义。
6. 用当前虫潮配置跑固定种子，观察击杀时间、清房时间、掩体破坏率、神力释放次数和背包满载率，再调系数。
7. 正式 Unity 接入时，把五行解析放进纯领域 BuildStats/Attribute 层，由战斗会话初始化 CombatantState、武器和资源快照。

## 10. 已确认与待确认规则

本轮已确认：

- 角色初始天赋按角色固定；局外养成可以改变初始天赋。
- 物品五行点进入基础伤害，伤害系数可以独立于当前原型重新校准。
- 火神力上限随火强度增长。
- 背包采用重量制，每件物品有重量；主动装备槽与携带负重可分开。
- 一整层（含 Boss）获得约 1~2 次赐福；普通战斗小关平均获得约 1.5 件物品，事件房和商店继续提供物品。
- 普通战斗清场时间目标在 60 秒以内，单怪 TTK 通常低于 5 秒；这是平衡目标，不是引擎强制时限。
- 主射的弹药账本改为气力消耗，金属性影响气力上限与攻击/翻滚消耗。
- 原型第一轮角色五行天赋统一使用全 C 占位，角色固定档位字段已预留。
- 主射每发固定消耗气力，按 `R` 进入回气；回气完成后恢复到气力上限。
- 负重超出土属性容量仍允许携带，但会提高气力消耗、降低主射速度并禁用闪避。
- 普通虫潮按有限出怪预算和阶段节奏生成敌人；约 40 秒是平衡目标，不是停止战斗或强制清房的截止时间。

仍需要决定的规则：

1. 物品五行点的等级成长，是每阶固定加点还是按稀有度给成长曲线。
2. 法力和神力是否允许在非战斗房间恢复，以及神力大招的固定消耗/释放形式。

## 11. 首版 DPS 校准结果

原型的 DPS 模拟按 60 Hz 推进射击、气力消耗、按 R 回气和副射蓄力；DPS 同时报告 60 秒房间窗口与 180 秒长窗口，两者都从满气力/满法力开始。TTK 使用固定随机种子做 256 次命中抽样，不受 DPS 窗口影响。身体与弱点 DPS 是 0%/100% 弱点命中的两个端点；期望 DPS 以 25% 弱点命中率作敏感性参考。下表假设命中率 100%、只打一个目标，用于比较构筑，不是实战承诺。

| 场景 | 60 秒身体 DPS | 60 秒期望 DPS（25%弱点） | 180 秒身体 DPS | 180 秒期望 DPS（25%弱点） | Boss 身体 TTK | Boss 弱点 TTK |
| --- | ---: | ---: | ---: | ---: | ---: | ---: |
| 开局·全 C 空装 | 49.00 | 55.13 | 48.47 | 54.52 | 17.95 秒 | 11.83 秒 |
| 中期·精准与法力 | 81.88 | 94.54 | 81.28 | 93.85 | 10.08 秒 | 6.23 秒 |
| 后期·火木扩散 | 193.34 | 259.66 | 192.20 | 258.11 | 4.35 秒 | 1.80 秒 |

后期高协同样例已经进入 Boss TTK 压力区，尤其全弱点命中时过快；这不是默认所有玩家都会达到的构筑，而是提醒后续要限制弱点倍率、攻速乘区和物品组合的叠加。当前单体报告不计算穿透的额外目标、击杀爆炸连锁、移动命中损失或房间出怪节奏；普通房清场时间另以固定种子虫潮模拟为约 40.9 秒、84 击杀，目标仍是 60 秒以内。

全 C 空装基线为主射 12 点/发、5 发/秒理论射速、3.92 发/秒持续射速、343 帧（约 5.72 秒）一个回气周期。混合轮转策略先起副射蓄力，让出启动当帧的主射，蓄力期间仍按射速继续主射；全 C 单体身体 DPS 从纯主射 49.00 提到 51.72（60 秒窗），Boss 身体 TTK 从 17.95 秒降到 16.02 秒。气力不足时会按原型输入规则打断蓄力并回气。该指标从满法力开始，不代表持续多房间的群体收益。

## 12. 物品首版设计约束

物品借鉴《雨中冒险 2》可见内容中的机制组织方式：把效果做成易读的常驻加成、明确触发与收益、可叠加收益，以及少数明确唯一的机制。只参考机制结构，不复制原作数值或文案；隐藏列不纳入参考。

- 22 件物品按新版神器流派标签分配；每件都有金水木火土点数和负重，元素点进入对应五行派生值，也以 0.10 系数进入基础伤害。
- 常规物品保持 1~2 条数值词条；存在特殊触发效果时，将其与词条分区展示。没有特殊触发的物品可以只靠五行点和数值词条成立。
- 重复获取时，元素点和重量始终累计；普通效果逐件叠加，只有显式标记“唯一效果”的物品，其战斗效果只应用一次。
- 重复物品按实际持有件数推进 2 件与 4 件流派协同；唯一效果标记不会阻止该物品副本参与流派件数。
- 效果文案采用可计算的数值描述，例如“弱点命中额外造成 5 点伤害”，避免“强化精准作战”这类不可测量的描述。

首版代表性机制包括：礼魂的回气联动、湘夫人的击杀扩散、云中君的弱点奖励、少司命的续命、太一的蓄力反制、九凤的火行攻速、巫咸的局外资源收益、河伯/湘君的法力副射循环、海若的掩体防护，以及首山玄女的蓄力收益。

当前角色五行初始天赋仍以全 C 占位，角色专属初始值和局外养成只是预留规则。火神力条目前是派生数值；本轮校准没有验证正式大招的花费、回能和施放循环。副射当前承载水属性法力循环；神力与法力的正式战斗行为仍需后续独立验证。
